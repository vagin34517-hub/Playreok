# Playerok Mini App

Telegram Mini App в стиле Playerok: сделки, кошельки, лидеры, профиль, пошаговый флоу
«Создать сделку», ссылки на сделку и режим воркера (подтверждение оплаты).

## ⚡ Главные настройки (в начале <script> в index.html)

```js
// Юзернейм бота без @ — используется в ссылках на сделку
const BOT_USERNAME = 'YOUR_BOT_USERNAME';

// ID ВСЕХ воркеров (из authorized_users.json) + админ.
// Только эти люди видят кнопку «Подтвердить оплату».
const WORKER_IDS = [
  7925674810, // админ
  // добавь остальных воркеров
];
```

⚠️ Замени `YOUR_BOT_USERNAME` на юзернейм своего бота и вставь все ID воркеров из `authorized_users.json`.

## 🔗 Ссылки на сделку

- После создания сделки генерируется ссылка вида
  `https://t.me/<BOT_USERNAME>?start=DEAL-XXXXXX` — её можно «Поделиться» или «Скопировать».
- При открытии мини-аппа по такой ссылке автоматически открывается экран сделки
  (читается `start_param` из Telegram WebApp).

## 👷 Воркеры

- Если ID открывшего есть в `WORKER_IDS` — он видит бейдж «Воркер» и кнопки
  «Подтвердить оплату» на карточках сделок и на экране сделки.
- Остальные пользователи этих кнопок не видят.

## 📤 GitHub Pages

1. Создай репозиторий → загрузи `index.html` (+ `.nojekyll`).
2. Settings → Pages → Source: **Deploy from a branch** → main / root.
3. Через 1–2 минуты получишь ссылку `https://ЛОГИН.github.io/РЕПО/`.
4. Вставь её в @BotFather → Bot Settings → Menu Button / Mini App.

## 🔒 Приватность

В коде нет личных данных. Имя/юзернейм/аватарка подтягиваются из Telegram
и видны только владельцу аккаунта. По умолчанию — «Гость».

## ⚠️ Важно: нужен бэкенд для реальной работы

Это статический файл — он показывает интерфейс и флоу, но сам по себе **не меняет**
состояние в боте. Чтобы «Подтвердить оплату» реально отмечало сделку в боте,
нужен API/бэкенд к `script2.py` (HTTP-эндпоинты + проверка Telegram initData).
Это отдельный шаг — можно добавить.
